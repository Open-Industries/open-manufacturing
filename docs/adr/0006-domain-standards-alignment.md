# ADR-0006: Domain-standards alignment as the organizing principle

| Field | Value |
|---|---|
| Status | Accepted |
| Date | 2026-11-03 |
| Standard traceability | ISO/IEC/IEEE 42010 (architecture decision record) |

## Context

Adopters in this vertical already think in these standards; aligning the core's language and shapes to them is what makes the core adoptable instead of merely generic.

## Decision

The bounded contexts and contracts are aligned with the vertical's own standards and frameworks — ISA-95 / IEC 62264, OPC UA / IEC 62541, ISO 22400, IEC 63278 (Asset Administration Shell), ISO 9001 — per the normative mapping in docs/domain/domain-standards.md (CR-5).

## Consequences

Alignment is documented per concept. Nothing here claims certification or conformance testing by any standards body.
